Games and files

Every game name you'll see, which file its questions come from, how it's played and where it is. Click a place to open the game there. Type any name or file name to find it: Grammar Check, reads, Gap Fill…

Easy to mix up

  • Fill the gap is one sentence (gaps.csv). Complete the text on the topic page and Gap Fill on the Starters page are a whole paragraph, and they share a file (reads.csv).
  • Grammar Check (called SPAG: Right or Wrong until 8 Nov) asks “is the grammar good or bad?” (buttons: Good Grammar, Bad Grammar) (right-wrong.csv). True or false asks “is this fact true?” (tf.csv). Spot the error is a paragraph to find the mistakes in (errors.csv).
  • Find the evidence (English page) and All-in English (Chinese page) are the same game from the same file (evidence.csv). Its side column says which page a row is for.
  • Word or meaning on the topic page is called What does it mean? and Which word? in the board games and Starters. Anagram in Starters is Unscramble on handouts. All of these come from words.csv.
